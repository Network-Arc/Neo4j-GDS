# 🧠 Graph-Based Fraud Detection with Neo4j

This repository contains a full walkthrough of building a fraud detection model using graph-based techniques in **Neo4j** and the **Graph Data Science (GDS)** library.

---

## 📄 Project Contents

- `FraudAnalysis-Neo4j-Notebook.md` — Technical notebook containing Cypher queries, data modeling, and GDS workflows for fraud detection
- `clients.csv` / `transactions.csv` — Sample data files (if applicable)
- `README.md` — Overview and usage instructions

---

## 🚀 Features

- Create a realistic graph model for financial clients and transactions  
- Run analytical Cypher queries to surface suspicious behavior  
- Use GDS algorithms for community detection, centrality, and anomaly spotting

---

## 🛠️ How to Run This

1. Install Neo4j Desktop or spin up a Neo4j AuraDB instance
2. Load the `clients.csv` and `transactions.csv` files (or use mock data)
3. Copy Cypher from the notebook into the Neo4j browser or script it using Python
4. Explore results using Neo4j Bloom or GDS visualizations
